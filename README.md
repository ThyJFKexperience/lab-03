## How to Use

Once the application is running you will see a list of cities along with a + and wrench button in the bottom left.
The + button can be used to add cities while the wrench button can be used to change/edit cities.

To Add Cities
- Press the + button and two text fields will appear asking the user to enter a city name and province
- After filling these fields out you can press Add to add the city to the bottom of the city list
- Or you can press cancel to cancel the city adding process and close the text window

To Edit Cities
- Press on a city in the list of cities to make a selection, and while no visible confirmation appears, your selection is saved until you press a new city
- Press the wrench button and two text fields will appear asking the user to replace the selected city's name and province with new ones
- Pressing confirm after providing a new name and province will change the selected city to those new details in the same position in the list
- Or you can press cancel to cancel the city adding process and close the text window
